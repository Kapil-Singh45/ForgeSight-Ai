# ForgeSight AI 

ForgeSight AI is a machine learning project I built to explore how computer vision can help detect defects in industrial products.

It uses PatchCore and ResNet-18 to find unusual patterns in product images and generate heatmaps that highlight possible defects.

### What it does
- Detects unusual patterns in product images
- Highlights possible defects using heatmaps
- Provides an interactive dashboard for inspection
- Displays anomaly scores and evaluation results

### Built With
Python, PyTorch, PatchCore, ResNet-18, Streamlit
